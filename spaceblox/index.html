The game

What is Spaceblox?

A logic puzzle about colors, among drifting pixel stars.

Each level is a grid with a few tiles already placed. Fill every empty cell so every color rule holds — no luck, no reflexes, just reasoning. Boards grow from small yellow-and-blue puzzles into ones with green tiles, purple shifters, locks and "=" / "×" links. A short tutorial teaches each idea before it appears, and a red highlight shows when a placement breaks a rule.

Built for five spare minutes or a quiet evening. How the calm pace was designed is in Designing a calm puzzle game.

What's in the game

Features

Play and progress

  • Guided tutorial and easy / medium / hard campaign
  • In-game rule guide, hints, undo / redo and hold-to-clear
  • Three optional star goals; mid-level progress saves

Achievements and settings

  • Achievements (bronze / silver / gold, plus hidden)*
  • Dynamic or static sky; separate music and SFX
  • Android: optional Play Games cloud save & sync*

Accessibility and languages

  • Colorblind mode*
  • Screen-reader labels for menus and play*
  • Seven languages (EN, ES, DE, FR, PL, KA, UK)

Platforms

  • Android: Google Play (free, ads)
  • Web: play in browser; progress stays on that device
  • Built with Godot; cloud save is Android-only

* Now on Android in version 1.1.0 (see the release notes below). Also in the browser where those features already shipped.
